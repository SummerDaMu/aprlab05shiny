
# aprlab05shiny

This repository contains a Shiny app to compare two Pokémon with data from [PokéAPI](https://pokeapi.co/), using the R package: `aprlab05`

## Installation

You can install shiny, and the development version of aprlab05 from [GitHub](https://github.com/), with:

``` r
# install.packages("pak")
pak::pak(c("shiny", "totoposeb/aprlab05"))
```

## Example

This is a basic example which shows you how to run the app:

``` r
shiny::runGitHub("aprlab05shiny", "SummerDaMu")
```

## R package

The R package that this app uses is available at [totoposeb/aprlab05](https://github.com/totoposeb/aprlab05).
